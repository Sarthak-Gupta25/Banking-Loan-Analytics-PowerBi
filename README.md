# Banking-Loan-Analytics-PowerBi
Interactive Banking Loan Analytics Dashboard built using Microsoft Power BI.

## 📊 Project Overview

This project presents an interactive Banking Loan Analytics Dashboard
developed using Microsoft Power BI.

The dashboard provides a high-level view of loan portfolio performance,
customer segments, loan status, default rates, age groups, income bands,
and loan types.

## 🎯 Objectives

- Analyze the overall loan portfolio
- Monitor outstanding loan balances
- Understand active, closed, and defaulted loans
- Analyze customer segments
- Examine loan distribution across age groups
- Analyze default rates by income band
- Compare different loan types
- Provide interactive filtering for business analysis

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization

## 🔍 Key Analysis Areas

### Loan Status
The dashboard compares:

- Active loans
- Closed loans
- Defaulted loans

### Customer Segmentation
Loan portfolio exposure is analyzed across:

- High Value customers
- Medium Value customers
- Low Value customers

### Age Analysis
Loan portfolio is segmented into age groups such as:

- 20–30
- 30–40
- 40–50
- 50+

### Income Analysis
Default rates are analyzed across different income bands.

### Loan Type Analysis
The dashboard compares loan portfolio values across different
loan products, including Home Loan, LAP, Business Loan, Car Loan,
Personal Loan, Education Loan, Agriculture Loan, Credit Line Loan,
and Gold Loan.
